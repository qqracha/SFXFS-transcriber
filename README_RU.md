# SFXFS Transcriber

Локальное приложение для транскрибации `MP4`, `MP3` и `WAV` в `TXT` и `Markdown`.

## Запуск

Дважды щёлкните `START_APP.cmd`. Интерфейс откроется в браузере автоматически.

Первый запуск может занять несколько минут: приложение создаст изолированное окружение. Если модель Whisper `small` уже осталась от проекта Postal 2, она будет найдена автоматически. В противном случае модель скачается при первой транскрибации.

## Как пользоваться

1. Перетащите MP4, MP3 или WAV в область выбора.
2. Укажите русский, английский или автоопределение языка.
3. Нажмите «Начать транскрибацию».
4. Следите за этапом, процентом, текущей позицией и оставшимся временем.
5. Скачайте готовый TXT или Markdown с таймкодами.

Результаты также сохраняются в папке `results`.

## Остановка

Запустите `STOP_APP.cmd`.

Файлы обрабатываются локально и не отправляются в облачный сервис. Временная копия исходного файла удаляется после обработки.
