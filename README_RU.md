# SFXFS Transcriber

Локальный транскрибатор Twitch VOD для подготовки разговорных стримов к монтажу в DaVinci Resolve.
На вход подаётся готовый файл, скачанный через TwitchDownloaderWPF: `MP4`, `MP3` или `WAV`.

## Запуск

Дважды щёлкните `START_APP.cmd`. Интерфейс откроется в браузере автоматически.

Первый запуск может занять несколько минут: приложение создаст изолированное окружение. Если модель Whisper `small` уже осталась от проекта Postal 2, она будет найдена автоматически. В противном случае модель скачается при первой транскрибации.

## Как пользоваться

1. Перетащите MP4, MP3 или WAV в область выбора.
2. Укажите русский, английский или автоопределение языка.
3. Нажмите «Начать транскрибацию».
4. Следите за этапом, процентом, текущей позицией и оставшимся временем.
5. Скачайте TXT/Markdown или структурированный JSON.
6. Для длинных стримов используйте LOGGER-входы: приложение создаёт окна по **25 минут** с overlap **5 минут**, сохраняя таймкоды исходного VOD.
7. В `Manual Mode` отправьте JSON в LOGGER/EDITOR/CUTTER и вставьте ответы обратно в блоке Manual pipeline.
8. В `OpenAI API` режиме задайте `OPENAI_API_KEY` в `.env`; транскрипция остаётся локальной, а JSON-анализ выполняется автоматически.

## DaVinci Resolve

FPS читается из файла автоматически через `ffprobe` (с fallback на PyAV). При необходимости укажите ручной override в поле FPS.

После завершения доступны три пары экспортов:

- `markers_cutter.edl` — основной экспорт для монтажёра;
- `markers_logger.edl` — смысловые эпизоды LOGGER;
- `markers_editor.edl` — идеи EDITOR;
- CSV-версии тех же файлов — для проверки и отчётности.

В Resolve используйте `Timelines → Import → Timeline Markers from EDL`. Цвета: LOGGER — Blue, EDITOR — Yellow, CUTTER — Green.

Результаты также сохраняются в папке `results`.

## Остановка

Запустите `STOP_APP.cmd`.

Файлы транскрипции обрабатываются локально и не отправляются в облачный сервис. Временная копия исходного файла удаляется после обработки. В OpenAI API режиме в облако отправляются только текстовые JSON-запросы AI-этапов.
